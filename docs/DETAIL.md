# Capability map（能力地图）

在会话右侧栏新增一个原生标签页，以**卡片网格**展示当前会话调用过的能力：

- 顶部类别筛选：**全部 / 技能 / 工具 / MCP**（带数量角标）；
- 每张卡片：能力图标 + 名称（MCP 卡片附服务器名），**右下角显示调用次数**，仍在运行的调用带呼吸圆点；
- 顶部一行统计：总调用次数 / 技能 / 工具 / MCP 种类。

## 使用

1. 打开一个会话，点右侧栏标签条上的 **「+」**；
2. 在 Guide 卡片网格中点击 **「能力地图」** 卡片，即打开本标签页；
3. 面板每 5 秒自动刷新，也可点右上角刷新按钮；顶栏「显示全部」可预览全部本地可用技能（未调用的计 0 次 / 未运行），默认只显示本会话调用过的能力。

## 实现与限制

- 数据来自宿主侧该会话的实时事件流（`tool/call` / `tool/result`），经 `/usage/api/summary` 同源路由提供给浏览器。
- MCP 工具按线上名前缀 `mcp__<server>__<tool>` 识别归类，卡片附服务器名。
- 仅统计**驻留中**的会话；冷（未驻留）会话不回读持久化日志，面板显示空态提示。
- 子代理（subagent）的调用不在主会话事件流内，不参与统计。
- 与 Better Sidebar 兼容：注册走原生 `sidebarRightTabs` 通道。
