# Capability map（能力地图）

在会话右侧栏新增一个原生标签页，以**卡片网格**展示当前会话调用过的能力：

- 顶部类别筛选：**全部 / 技能 / 工具 / MCP**（带数量角标）；
- 每张卡片：能力图标 + 名称（MCP 卡片附服务器名），**右下角显示调用次数**，仍在运行的调用带呼吸圆点；
- 顶部一行统计：总调用次数 / 技能 / 工具 / MCP 种类。

## 使用

1. 打开一个会话，点右侧栏标签条上的 **「+」**；
2. 在 Guide 卡片网格中点击 **「能力地图」** 卡片，即打开本标签页；
3. 面板每 5 秒自动刷新，也可点右上角刷新按钮；顶栏「显示全部」可预览全部本地可用技能（未调用的计 0 次），默认只显示本会话调用过的能力。

## 实现与限制

- 数据来自宿主侧该会话的实时事件流（`tool/call` / `tool/result`），经 `/usage/api/summary` 同源路由提供给浏览器。
- 顶栏搜索按 **名称 / MCP 服务器名 / 标签文本** 过滤（标签同时匹配可见文案与 kind id，如 `其他`、`market`）。
- MCP 工具按线上名前缀 `mcp__<server>__<tool>` 识别归类，卡片附服务器名。
- **来源徽标判定**（7 种 + MCP 服务器名）：
  - 技能 kind 由**宿主**判定；工具则由宿主下发 `origins` 与官方工具名集合，**浏览器**按线上名匹配（精确名 → `*` 通配 → 官方名成员）后渲染，旧宿主缺字段时按旧行为回退。profile 目录与安装根取自运行时 profile 上下文（`DSH_PROFILE_DIR` / `DSH_INSTALL_DIR` 仅作兜底），profile 依赖表按 `package.json` 的 mtime 缓存。
  - **技能**（第一个命中即定）：① 显式技能根优先——`project-dsh`/`project-agents` → `项目`，`user-dsh`/`user-agents` → `用户`（否则 JS 仓库里的项目技能会命中仓库自己的 `package.json`）；② 技能文件 `path` 向上找最近的 `package.json`——包名命中 `officialPackages` 前缀（默认 `@deepseek-ai/`）→ `内置`，其余按该包在 profile 里的安装规格归 `市场`/`Git`/`本地`；profile 未声明的包继续往下判定，不再直接算 `其他`；③ `bundled` 技能路径被注册表改写、回溯不到包时，查**名字索引**（扫描已装包的 `skills/`、`assets/` 目录，含 frontmatter 名与扁平 `.md`）；④ 路径在安装树内 → `内置`；⑤ 未声明包位于 `node_modules` 内 → `其他`；⑥ 否则按 `source`：`custom` → `本地`，其余（含单独的 `bundled`）→ `其他`。`source: bundled` 不代表官方（第三方 bundle 同样报 `bundled`）；本会话调用过但已不在目录里的技能也回落 `其他`。
  - **工具**：定义里没有归属包字段，所以 ① 配置 `origins` 优先（精确名 → `*` 通配，如 `blender_rt_*`），按该包安装规格归类；② 否则命中官方工具名集合 → `内置`（静态清单 `OFFICIAL_TOOL_NAMES` + 扫描已装 `@deepseek-ai/dsh-tool-*` 包 + 安装内 `docs/tool-catalog.md` 为「本安装确实存在的官方包」列出的名字，DSH 升级无需插件发版）；③ 其余 → `其他`。
  - **MCP 工具**：永远显示服务器名（橙色徽标），`origins` 不生效。
- **卡片排序**：筛选行最右侧的「标签 / 次数」切换——`标签`（默认）按徽标优先级 `内置 → 项目 → 用户 → 本地 → Git → 市场 → 其他`，同级按名称；`次数` 按本会话调用次数降序，次数相同再按徽标、名称。MCP 卡片按服务器名 → 工具名（次数模式先比次数）；「全部」仍分 技能 / 工具 / MCP 三块，块内各自排序。
- 仅统计**驻留中**的会话；冷（未驻留）会话不回读持久化日志，面板显示空态提示。
- 子代理（subagent）的调用不在主会话事件流内，不参与统计。
- 与 Better Sidebar 兼容：注册走原生 `sidebarRightTabs` 通道。
